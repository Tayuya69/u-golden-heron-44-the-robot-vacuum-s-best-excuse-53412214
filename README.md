One-line entry for the [make.fun "Haunted Spot" bounty](https://make.fun/competitions/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214): the robot vacuum's best excuse for missing a spot.

> I didn't miss that spot. My lidar filed it under 'haunted' and my bumper refused to go back.

`main.ts` deterministically writes exactly that line (92 characters, no trailing newline) to `/output/entry.txt`. No randomness, no network, no input.
